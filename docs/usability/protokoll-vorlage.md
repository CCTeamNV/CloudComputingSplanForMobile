## Fragebogen SUS (von der Testperson auszufüllen)

1 = stimme überhaupt nicht zu … 5 = stimme voll zu. Eine Zahl pro Aussage, spontan antworten.

| Nr. | Aussage | 1–5 |
|---|---|---|
| 1 | Ich denke, dass ich die App gerne häufig benutzen würde. | |
| 2 | Ich fand die App unnötig komplex. | |
| 3 | Ich fand die App einfach zu benutzen. | |
| 4 | Ich glaube, ich bräuchte die Hilfe einer technisch versierten Person, um die App benutzen zu können. | |
| 5 | Ich fand, die verschiedenen Funktionen der App waren gut integriert. | |
| 6 | Ich fand, die App enthielt zu viele Ungereimtheiten. | |
| 7 | Ich kann mir vorstellen, dass die meisten Menschen den Umgang mit der App sehr schnell lernen. | |
| 8 | Ich fand die App sehr umständlich zu benutzen. | |
| 9 | Ich fühlte mich bei der Benutzung der App sehr sicher. | |
| 10 | Ich musste eine Menge lernen, bevor ich mit der App zurechtkam. | |

**SUS-Wert** (Moderation rechnet): ungerade Aussagen (1, 3, 5, 7, 9) jeweils Antwort − 1, gerade Aussagen (2, 4, 6, 8,
10) jeweils 5 − Antwort; Summe × 2,5 = **____ / 100**. Grobe Einordnung: ab ca. 68 überdurchschnittlich, ab ca. 80 gut.
